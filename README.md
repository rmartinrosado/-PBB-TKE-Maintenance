# PBB TKE Maintenance — Rediseño visual
Inspiración visual: panel azul pizarra, iconos lineales sobre tarjetas ámbar/naranja, esquinas redondeadas y jerarquía visual clara.

## Publicar
Sube los siete archivos a la raíz del repositorio GitHub Pages y reemplaza los anteriores. Tras publicar, abre la web en Safari y recarga. Si la app instalada no actualiza, cierra la PWA y vuelve a abrirla.

## Alcance
La aplicación comienza sin datos. Órdenes e histórico se guardan localmente. No existe sincronización entre dispositivos ni base de datos remota en esta versión. Los documentos seleccionados solo se listan en la sesión; no se guardan. Coteja bornes, conductores y módulos con los planos RCS vigentes y el procedimiento autorizado.
