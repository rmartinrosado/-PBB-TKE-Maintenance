# PBB TKE Maintenance v2.0 — Rediseño profesional

Sube los siete archivos a la raíz del repositorio de GitHub Pages, reemplazando los anteriores: `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `service-worker.js`, `icon.svg`, `README.md`.

Tras publicar, abre la web en Safari y recarga. Si la versión anterior sigue en caché, cierra la PWA y vuelve a abrirla.

Incluye órdenes, histórico, importación/exportación JSON y apartado de documentación. Comienza sin datos. Los registros se almacenan localmente en este dispositivo; la sincronización entre dispositivos y la base de datos remota no están configuradas. Los documentos seleccionados solo se listan durante la sesión. Coteja siempre con documentación RCS vigente y procedimientos TKE.
